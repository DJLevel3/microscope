# microscope

### A downright microscopic software oscilloscope!

This is the repository for the source code of a super-tiny software oscilloscope for the demoscene, with the primary goal of absolutely minimizing filesize using sizecoding techniques.

This project is written specifically for Windows/MSVC due to core differences in APIs and sizecoding technology between Windows and Linux. However, microscope should work fine with Wine, since the core Windows APIs are well-supported, although this is not a focus of the project.
